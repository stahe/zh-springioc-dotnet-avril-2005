# .NET 版 Spring IoC

➡️ 相关课程：**[.NET 版 Spring IoC](https://stahe.github.io/zh-springioc-dotnet-avril-2005/)**

本文介绍了**控制反转（IoC – Inversion of Control）**的原则，以及如何借助**Spring.NET**框架在**.NET**生态系统中实现这些原则。Spring.NET是最初为Java设计的**Spring**框架的移植版本。

本文旨在展示如何通过**解耦组件**并将组件的组装工作委托给配置容器，从而优化应用程序的设计。

---

# 文档目标

本教程的目标如下：

- 探索在 .NET 应用程序中**配置和集成 Spring 框架**的可能性

- 学习如何使用 **依赖注入（Dependency Injection）** 来解耦组件  
- 在 **VB.NET 的具体示例** 中实现这些概念

# 原理：控制反转 (IoC)

在经典架构中，一个对象：
- 自主创建其依赖项；
- 直接控制其所需的对象;

采用 **IoC** 时：

- 依赖关系由 **容器注入**;
- 组件之间实现 **松耦合**;
- 配置被 **外部化**;

这使得：

- **更佳的可维护性**
- **更高的可测试性**
- **更灵活的架构**

# Spring 理念

Spring 的主要价值不仅在于其技术机制，更在于其 **设计理念**：

- 角色分离  
- 组件间低耦合  
- 外部依赖配置  
- 测试驱动架构

这些原则有助于设计出**更简单、更模块化且更健壮**的应用程序。
